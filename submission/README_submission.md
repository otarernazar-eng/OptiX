# OptiX Medical - Submission

Проект **OptiX Medical** представлен на оценку жюри в рамках хакатона/конкурса.

## 🚀 Быстрый запуск для Жюри (Демо-режим)
В приложении встроен функционал "Демо-режима", который позволяет оценить алгоритмы без наличия реальных медицинских данных.

1. Убедитесь, что установлен Python 3.10+.
2. Перейдите в корневую папку проекта.
3. Установите зависимости: `pip install -r requirements.txt`
4. Запустите интерфейс: `streamlit run app/main.py`
5. На Главной странице в блоке **"🧪 Демо-режим"** скачайте синтетические снимки сетчатки (Норма и Патология).
6. Загрузите их на странице **"Анализ"** для проверки работы нейросети, тепловых карт и генератора PDF-отчетов.

*(Альтернативно проект запускается одной командой `docker-compose up --build -d`)*

## 📂 Структура папки submission/
- `presentation.pdf` — Слайды презентации (Питч-дек).
- `poster.pdf` — Инфографика (постер) для демонстрационного стенда.
- `scientific_report.pdf` — Детальное описание архитектуры (Фокальный Loss, Grad-CAM, Albumentations, метрики).
- `demo_video_script.md` — Сценарий трехминутного питчинга.
- `checklist.md` — Ответы на популярные вопросы жюри (Q&A) и технический чек-лист.

## ⚙️ Основной репозиторий
Весь модульный код (пайплайны, нейросети, фронтенд) находится в корневой папке (`src/` и `app/`). Код прошел процедуру рефакторинга по стандартам PEP8 (Type Hints, Docstrings).

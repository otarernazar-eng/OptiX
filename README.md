# OptiX 👁️

ИИ-помощник, который по фото сетчатки глаза определяет у недоношенных детей риск тяжёлого заболевания (ретинопатии), помогая врачам быстрее выявлять проблему.

## 📂 Структура проекта

```text
OptiX/
├── app/                    # Streamlit-приложение (веб-интерфейс)
│   ├── main.py             # Главная страница
│   └── pages/              # Страницы (Анализ, Результаты, О проекте)
├── src/                    # Исходный код пайплайна
│   ├── data/               # Скрипты для обработки данных
│   ├── models/             # Архитектуры моделей
│   ├── utils/              # Вспомогательные функции (напр. загрузка конфига)
│   ├── train/              # Скрипты для обучения
│   ├── inference/          # Скрипты для получения предсказаний
│   └── evaluation/         # Скрипты для оценки моделей
├── configs/                # YAML-конфигурации
│   └── base.yaml           # Базовый конфиг (размер картинки, архитектура и т.д.)
├── tests/                  # Модульные тесты (pytest)
├── models/                 # Сохранённые веса моделей (ONNX, pt)
├── data/                   # Данные для обучения и тестов
│   ├── raw/                # Сырые данные
│   ├── processed/          # Обработанные данные
│   └── splits/             # Разбиения (train/val/test)
├── docker/                 # Конфигурация Docker

└── README.md               # Документация проекта
```

## 🚀 Запуск локально (через Python)

1. Создайте виртуальное окружение:
```bash
python -m venv venv
source venv/bin/activate  # Для Linux/Mac
venv\Scripts\activate     # Для Windows
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Запустите Streamlit-приложение:
```bash
streamlit run app/main.py
```

## 🐳 Запуск через Docker (Production)

Проект полностью готов к контейнеризации. Это рекомендуемый способ запуска приложения для больниц, обеспечивающий изолированность и безопасность.

1. Убедитесь, что у вас установлен [Docker](https://www.docker.com/) и Docker Compose.
2. В корневой директории проекта выполните команду:
```bash
docker-compose up --build -d
```
3. Приложение будет доступно в браузере по адресу: [http://localhost:8501](http://localhost:8501)

Все ваши данные, обученные веса моделей и сгенерированные отчеты будут сохраняться на вашей хост-машине, а не внутри контейнера (благодаря настроенным `volumes`).

## ⚙️ Конфигурация
Все основные параметры (размер изображения 384x384, архитектура EfficientNet-B0 и др.) задаются централизованно в файле `configs/base.yaml`. Все скрипты в проекте читают конфигурацию оттуда с помощью `src/utils/config.py`.

## 🧪 Тестирование
В проекте настроены модульные тесты с использованием Pytest для автоматической проверки критических узлов (аугментации, сборка батчей, размерности инференса). 
Для запуска всех тестов выполните:
```bash
pytest tests/ -v
```
